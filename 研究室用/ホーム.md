# 論文探索

気になる論文のPDFと、内容を整理したノートをまとめます。[[論文一覧.base|論文一覧]]で書誌情報や興味度を比較できます。

## PDFを追加して整理する

1. 気になるPDFを「00 PDF受け取り」フォルダに入れます。
2. このチャットで、追加した論文の整理を依頼してください。指定の項目を調べ、「論文ノート」に1論文につき1ノートを作成します。
3. 整理したPDFは「01 論文PDF」に移し、ノートのPDFプロパティからリンクします。
4. 内容を確認し、ノート上部の `tags` プロパティで自分の興味度を設定します。

## 興味度を設定する

`tags` に次のいずれか1つを入力します。興味度は自分で判断できるよう、最初は空欄にしておきます。

| タグ | 興味度 |
| --- | --- |
| `high` | 高い |
| `middle` | 中くらい |
| `low` | 低い |

変更するときは、以前の興味度タグを削除してから新しいタグを付けます。[[論文一覧.base|論文一覧]]の `high`・`middle`・`low`・「興味度未設定」の各ビューで絞り込めます。

## フォルダの役割

| フォルダ | 保存するもの |
| --- | --- |
| 00 PDF受け取り | これから整理するPDF |
| 01 論文PDF | 整理済みノートから参照するPDF |
| 論文ノート | 論文ごとの書誌情報と内容の整理 |
| 90 テンプレート | [[90 テンプレート/論文整理テンプレート|論文整理テンプレート]] |

## ノートに記録する項目

ノート上部のプロパティには、タイトル、ジャーナル、出版名（出版社名）、著者名、出版年、DOI、URL、PDF、読書状況、興味度タグ、作成日を記録します。

本文では、アブストラクト、背景、方法、結果、考察、先行研究との新規性、限界、応用可能性を整理します。著者の主張と自分の考察を分け、根拠となるページ・節・図表番号や出典を添えます。未確認の情報は推測で補いません。

## 自分でノートを作る場合

「論文ノート」に新しいノートを作り、ファイル名を「出版年 筆頭著者 短いタイトル」にします。コマンドパレット（⌘P）から「テンプレートを挿入」を選び、「論文整理テンプレート」を挿入してください。読書状況は「未読」「読書中」「整理済み」で管理します。
