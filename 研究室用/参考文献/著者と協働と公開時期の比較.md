# 著者と協働と公開時期の比較

著者全員は各ノートのプロパティに記録しています。[[論文一覧.base|論文一覧]]の「著者と協働と公開時期」ビューでは、著者・協働・公開日・新規性を並べ、確認できた文書の初公開日が新しい順に表示します。

## 公開時期と新規性

公開時期の新しさと研究内容の新規性は別の項目です。初公開日は確認できた文書のオンライン公開日、参照版公開日は実際に読んだ版の日付、出版年は論文集・ジャーナル等の書誌年です。学会発表が先行する場合は発表年も記録します。日付が不明な場合は推測で埋めません。

## 協働ロボットの読み方

ここでは、人とロボットが共同作業や誘導・追従を行う研究かを、論文に記載された範囲で分類します。産業用cobotという機種分類とは区別し、使用ロボットと関わり方を併記します。「実証なし」は、そのロボットに協働能力がないという意味ではありません。

| 論文 | 協働の記録 | 根拠・範囲 |
| --- | --- | --- |
| 避難者行動モデル | 有（避難誘導型HRI） | 実環境で人の追従を観察。1台の先導と3台の引き継ぎを扱う。機種は未記載 |
| ALOHA／ACT | 遠隔操作あり。自律協働は未実証 | 人の実演収集と、自律操作の評価を区別する |
| ASAP | 人との協働実験なし | G1の単体全身動作。人の動画を参照することと共同作業は別 |
| ANYmal Parkour | 人との協働実験なし | ANYmal Dの単体自律移動を評価 |
| AIとマーケティング | 該当なし | 概念論文。独自の実機実験はない |

各行の詳しい根拠、実験結果、著者の新規性主張と整理上の考察は、リンク先の論文ノートを参照してください。
