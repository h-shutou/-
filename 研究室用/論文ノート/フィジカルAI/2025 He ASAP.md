# ASAP

正式タイトル：ASAP: Aligning Simulation and Real-World Physics for Learning Agile Humanoid Whole-Body Skills。

**要点：実機で得た軌跡を使って「シミュレーションに加える行動の補正」を学び、その補正を組み込んだ環境で人型ロボットの動作方策を再学習する。** 最終的な実機実行では補正モデルを使わず、再学習した方策だけを動かす。（Fig.2、II・III節、PDF pp.2–5）

参照版はarXiv:2502.01143v3。Google Scholar由来の資料とは区別する。興味度は `tags` に `high`・`middle`・`low` のいずれか1つを設定する。

## アブストラクト

シミュレーションと実機の物理特性の差は、ヒューマノイドの跳躍や片脚バランスなどの俊敏な全身運動を妨げる。ASAPは、人の動きをロボットへ変換してシミュレーションで動作追従方策を事前学習し、次に実機データから残差行動モデルを学習する2段階の枠組みである。残差モデルでシミュレーションを実機の挙動に近づけ、その環境で方策を微調整する。異なるシミュレータ間とUnitree G1実機への転移を評価し、追従誤差の改善を報告する。（要旨、PDF pp.1–3）

## 背景

全身の素早い動作では、モータの応答、関節機構、モデル化しきれない物理特性の違いが追従誤差を生む。従来のシステム同定（SysID）は事前に決めた物理パラメータの範囲に依存し、ドメインランダム化（DR）は広い条件に耐える代わりに保守的な方策を生む場合がある。著者らは、物理パラメータや次状態を直接推定する代わりに、**実機とシミュレーションの差を行動空間の補正として学べるか**を問う。（I節、PDF pp.2–3）

## 方法

### 事前学習と残差による物理の整合

1. 人の動画からTRAMでSMPL形式の3次元動作を推定する。
2. MaskedMimicを用いたシミュレーションで物理的な不整合を除き、G1の体格・関節構成へ動作を変換する。
3. 固有感覚の履歴と動作位相を入力する追従方策をPPOで学習する。実機で使うactorは外部の位置ベース目標を入力にしない。
4. 方策を実機で実行し、モーションキャプチャと機上センサで状態・行動を記録する。
5. 記録した行動をシミュレーションで再生し、実機軌跡とのずれを小さくする残差行動モデルをPPOで学習する。
6. 残差モデルを固定してシミュレーションへ組み込み、元の追従方策を再学習する。実機へは再学習済み方策だけを展開する。

根拠：II・III節、Fig.2・3（PDF pp.2–5）。残差は実機の行動に後付けする運用時の補正器ではなく、訓練環境の物理差を表す役割である。

### 実験条件

| 項目 | 設定 |
| --- | --- |
| 実機 | 手首を固定したUnitree G1。追従方策は23自由度の関節目標を出力 |
| 転移先 | IsaacGym → IsaacSim、IsaacGym → Genesis、IsaacGym → 実機G1 |
| シミュレーション評価 | 43動作をeasy・medium・hardに分類 |
| 実機のデータ収集 | キック、前方ジャンプ、前後ステップ、片脚バランス、片脚ジャンプを選ぶ。約100動作クリップと10分の移動データを収集 |
| 残差モデルの実機条件 | 全23自由度ではなく、足首の4自由度だけを補正。フルモデルとは区別する |
| 実行回数の記載 | IV-C節では各タスクの追従方策を30回実行と記載。Table Vの定量比較はキックとSilencerの2動作 |
| 比較 | 微調整前のVanilla、SysID、残差状態モデルDeltaDynamics。実機のTable VはVanillaとの比較 |
| 評価指標 | 大域的関節位置誤差E_g-mpjpe、root相対のE_mpjpe、加速度・速度誤差、動作追従の成功率 |

根拠：IV節、Table III–V（PDF pp.5–9）。シミュレーションの全身残差モデルの結果を、実機で全身補正を学習した証拠と混同しない。

## 結果

### 実機での追従誤差

| 実機動作 | 指標 | 微調整前Vanilla | ASAP |
| --- | --- | --- | --- |
| キック（学習分布内） | 大域的関節位置誤差（mm） | 61.2 | 50.2 |
| キック | root相対関節位置誤差（mm） | 43.5 | 40.1 |
| LeBronのSilencer（残差モデルに対する分布外動作） | 大域的関節位置誤差（mm） | 159 | 112 |
| Silencer | root相対関節位置誤差（mm） | 55.3 | 47.5 |

出典：Table V（PDF p.9）。どちらの誤差も小さいほどよい。Silencerへの適用では、その動作用の方策を学習済み残差モデルで微調整しているため、追加学習なしの未知動作の即時実行とは異なる。

### シミュレーションでの転移と分析

- Genesisのhard条件では、大域的関節位置誤差がVanillaの175mmからASAPの129mmへ改善。成功率は82.9%から100%へ改善する。**これはシミュレーションでの値**であり、実機全体の成功率100%を意味しない。（Table IV、PDF p.7）
- easy条件の一部指標では他手法のほうが小さい値もあり、「全条件・全指標で最良」とは読まない。動作難度と評価指標を区別する。（Table IV）
- 残差モデル用のデータ増加は分布外軌跡への適合を改善するが、方策の閉ループ性能の改善は飽和する。残差を学ぶ時間幅も、長ければ常に最良というわけではない。（V-A節、Fig.10、PDF p.10）
- 残差を固定点反復や勾配探索で直接利用する方法より、残差入り環境でのRL微調整がよい追従を示す。（V-B節、Fig.11、PDF pp.10–11）

## 考察

### 著者の解釈

関節ごとの物理差は一様ではなく、足首や膝などに大きなずれがある。これを残差行動としてモデル化すると、単なるランダムな行動ノイズより実機に沿った再学習ができると論じる。重要なのは、観測された物理差を再現する環境で方策を訓練し直す点である。（V・VI節、PDF pp.10–12）

### 整理時の検討メモ

以下は整理上の考察であり、著者の実証済み結論や利用者自身の意見ではない。

- 実機の失敗をシミュレーションに再現できるかを中間評価に置く点は、sim-to-realの原因を切り分ける実験設計として参考になる。
- ずれの大きい足首に対象を絞る設計は、限られた実機データでどの関節を補正すべきかという研究課題につながる。

## 先行研究との新規性

| 先行アプローチ | ASAPの位置づけ |
| --- | --- |
| SysIDによる質量・重心・制御ゲイン等の調整 | 事前に定めたパラメータだけでなく、状態と行動に条件づけた残差行動でずれを表現 |
| ドメインランダム化 | 幅広い物理条件への耐性に加え、観測した実機軌跡へ訓練環境を近づける。事前学習ではDRも併用 |
| 残差状態・動力学モデル | 次状態を直接補正する代わりに、物理シミュレータへ入力する行動を補正 |
| 既存の残差学習・RGAT | 残差を用いてシミュレータを整える既存発想を踏まえ、RLによる整合と俊敏なヒューマノイド全身技能へ展開 |

## 限界

### 著者が明示する限界

- **実機の負荷と故障**：俊敏な動作の収集でモータが過熱し、実験中にG1の2台が一部故障したと報告する。
- **モーションキャプチャ依存**：整合用の実機軌跡収集にMoCapが必要。最終方策の入力と、学習データ収集の要件は区別する。
- **全身モデルのデータ量**：23自由度の残差学習にはシミュレーションで400超のクリップが必要とされ、実機では4自由度へ縮小した。

根拠：IV-C・VIII節（PDF pp.8、12）。

### 適用範囲の評価

- 実機の定量比較は代表2動作であり、一般的な作業・未知の地面・物体との接触を網羅した評価ではない。
- Table Vには誤差の値が示されるが、標準偏差や信頼区間は併記されていない。効果のばらつきを表だけから判断しない。
- 人の動作の復元・変換、報酬、許容誤差のカリキュラムなど複数の設計を前提とする。残差モデル単体だけで全成果を説明しない。

## 応用可能性

### 論文が示した範囲

G1のキック、跳躍、片脚支持など、俊敏な参照動作を実機へ転移するための学習基盤。シミュレータ間の物理差を比較する研究にも利用できる。（IV節）

### 追加の応用アイデア

実機の個体差、モータ交換や経年変化によるずれの再整合に応用する研究が考えられる。防災ロボットへの適用は本論文では未検証で、移動地形、転倒・損傷、データ収集の安全性を別に評価する必要がある。

## 疑問と次に調べること

- [ ] 興味度を設定する。
- [ ] MoCapなしで整合用の軌跡を収集できるか。
- [ ] 少量のデータで、足首以外や別個体に補正を広げられるか。
- [ ] 残差が大きい関節の選択と、実機の損傷を抑える収集を両立できるか。
- [ ] 分布外の動作・摩擦・接触条件で、どこまで補正を再利用できるか。
