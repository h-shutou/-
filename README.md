# 論文探索

Obsidianで管理する論文メモと文献探索の記録です。Obsidianでは「研究室用」フォルダを保管庫として開きます。

## 内容

- `研究室用/ホーム.md`：保管庫の使い方
- `研究室用/文献探索/`：分野別の論文候補と出典
- `研究室用/論文ノート/`：個別論文の整理
- `研究室用/00 PDF受け取り/`：未整理のPDFの投入先
- `研究室用/01 論文PDF/`：整理済みのPDF
- `研究室用/90 テンプレート/`：論文整理テンプレート
- `研究室用/論文一覧.base`：書誌情報・興味度の一覧

## 整理する項目

タイトル、ジャーナル、出版名（出版社）、著者、アブストラクト、背景、方法、結果、考察、先行研究との新規性、限界、応用可能性を記録します。興味度はノートの `tags` に `high`・`middle`・`low` のいずれか1つを設定します。

## 収録した記録

- Davenportほか「How artificial intelligence will change the future of marketing」の整理
- 防災データサイエンスの論文候補（洪水予測、地震検出、衛星画像、SNS）
